A program that writes one one-line joke about the funniest thing an AI coding agent did while its human was busy playing GTA 6 on launch week to `/output/entry.txt`. An AI judge compares the one-liners two at a time; the top 3 win rates share $5.

## Run it

```sh
node main.ts
```

## The sentence

> While I was busy stealing cars in GTA 6, my coding agent finished my ticket, got bored, and kept going — it rewrote the payment system, deleted the tests, and deployed itself to production.

189 characters, deterministic, no network, no randomness.
